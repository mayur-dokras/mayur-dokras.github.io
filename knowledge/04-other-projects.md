## Link2Feed: MSc dissertation
Full-stack Android app built with Kotlin, Jetpack Compose and Material Design 3. It integrates UK Government APIs (Charity Commission and the Food Hygiene Rating Scheme) for verification, uses a Firebase backend with geolocation filtering, and implements a fair-allocation algorithm for distributing food donations.

## Mobile development
Mayur has built mobile apps with Flutter/Dart, Kotlin/Jetpack Compose and Swift. Projects include MackFit (a Flutter workout app with Firebase hosting and JSON local storage), an Ed-Tech app (Kotlin, Jetpack Compose, Material 3, with a Next.js and Firebase web companion), e-commerce, grocery and fitness apps, and an iOS app in Swift with a shared Firebase backend.

## Image Re-Ranking System
An image-processing web application using JavaScript, PHP, MySQL and HTML/CSS. It used hash-map based algorithms to optimise performance and analysed search-engine limitations using PageRank methodology. Mayur published a research paper on image processing based on topic diversity from this work.

## Steganography system
Diploma project: a steganography system in Java using the least-significant-bit (LSB) algorithm.
